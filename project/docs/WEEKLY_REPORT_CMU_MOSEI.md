#### 2.3 `organize_cmu_mosei_raw.py`
- **功能**：处理从 Kaggle 下载的原始 CMU-MOSEI 数据
- **位置**：`project/scripts/organize_cmu_mosei_raw.py`
- **特点**：
  - 自动检测目录结构（支持多种 Kaggle 数据格式）
  - 识别视频、音频、文本文件

  - 生成完整的训练数据格式
