## 五、遇到的困难与解决办法

### 5.1 数据与配置类

| 困难 | 解决办法 |
|------|----------|
| 数据路径为 `None` 导致 `stat: path should be string...` | 在 `dataset.py` 的 `_load_*` 中先判断 `path is None` 再调用 `os.path.exists`，缺失模态返回 `None`，在 `__getitem__` 中用零张量替代以保证 DataLoader 可 collate。 |
| 配置中 `wav2vec2-base` 导致 HuggingFace 404 | 将 `config.yaml` 中 `model.audio.backbone` 改为 `"facebook/wav2vec2-base"`。 |
| `output_config` 等变量在模型初始化中引用顺序错误 | 在 `multimodal_model.py` 中将 `output_config`、`hidden_dim` 等定义提前到使用之前。 |
| DataLoader 报错“batch 中含 NoneType” | 在 `__getitem__` 中对缺失的 video/audio/text 等统一返回规定形状的零张量，避免 collate 时出现 None。 |
| BalancedDatasetSampler 初始化极慢 | 改为直接基于 `dataset.data_list` 按 `dataset_id` 分组索引，避免在初始化时对每个样本做完整加载。 |

### 5.2 显存与训练稳定性

| 困难 | 解决办法 |
|------|----------|
| 端到端 VAT + 大 batch 导致 OOM | 将 batch_size 降至 4，视频 `frame_size=160`、`num_frames=8`；暂时关闭视频模态，采用 AT 配置以先跑通基线。 |
| 域适应 / DatasetSpecificNormalization 导致 DivBackward0 等梯度 NaN | 暂时关闭域适应与数据集特定归一化（config 中 `enabled: false`），并在 `DatasetSpecificNormalization.forward` 中对输入与方差做 `nan_to_num` 和 `clamp_min`，便于日后重新开启。 |
| 融合/分类头处出现 AddmmBackward0、LogSoftmaxBackward0 等 NaN | 在 `multimodal_model.py` 中对送入分类器前的 `pooled_features` 做 `nan_to_num`；在损失计算前对 `emotion_logits` 做 `nan_to_num`，避免 NaN/Inf 传播。 |
| checkpoint 保存报错“Parent directory checkpoints does not exist” | 在项目根目录下执行 `mkdir -p checkpoints`，保证保存路径存在。 |

### 5.3 其他

| 困难 | 解决办法 |
|------|----------|
| 训练中反复出现 “moov atom not found” | 确认为 ffmpeg 对部分损坏/非标准 mp4 的警告，不导致中断；当前 AT 基线未使用视频，影响极小，可在论文中简述为数据噪声。 |
| TensorBoard 在远程服务器上查看 | 通过 SSH 端口转发（如 `ssh -L 6006:localhost:6006 -p 端口 用户@服务器`）在本地浏览器访问 `http://localhost:6006` 查看 TensorBoard。 |
