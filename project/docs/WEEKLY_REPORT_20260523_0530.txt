3. 测试与问题排查

   （1）连通性
       - 现象：浏览器转发 127.0.0.1:8000，video 分块 8/37 报 Failed to fetch。
       - 结论：非模型 bug，为隧道对大量小 POST 不稳定；推荐单端口 8000 或公网 nginx 直连。
       - 处理：批量分块 API、降低码率、dev 模式 JPEG 阈值；server 模式整包 multipart；
         规划公网 nginx 消除 Cursor 隧道。

   （2）准确性
       - 现象：ASR「我很难过/我很伤心」置信 ~0.9，情绪 Top1 neutral（~0.50），sad ~0.13；
         trace 显示 bert-base-uncased、single_frame_fallback（1/4 帧）。
       - 结论：英文 BERT + 英文三数据集权重 + 中文域偏移 + 视频信息不足，四因素叠加；
         需 bert-base-chinese 微调并恢复 webm 多帧后再评估。
       - 处理：启动 bert-base-chinese 微调；LLM 改读模型概率而非仅依赖 ASR 文本。

   （3）本地自测
       - curl /api/v1/health、infer-upload（文本）可返回 inference_source=checkpoint。
       - 整包 multipart 与分块接口在 localhost 可用；公网 HTTPS 验收待部署。

二、智能体端到端数据流
--------------------------------------------------------------------------------

  浏览器采集（摄像头+麦克风）
    → webm 视频 clip + wav 音频（或 dev 模式 JPEG 回退）
    → POST /api/v1/emotion/infer-upload 或分块上传 + infer-from-upload
    → 后端 ASR（9010）→ 文本合并 → MultimodalEmotionModel（CUDA, ap2_m1）
    → 七类概率 + valence/arousal
    → POST /api/v1/agent/respond（Ollama，注入 all_probs）
    → 前端展示情绪条、pipeline_trace 四阶段、助手回复
