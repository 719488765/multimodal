二、AP4 实验结果深度分析
--------------------------------------------------------------------------------

1. 实验协议（便于与 AP0–AP3 对照）

   固定条件：AVT 三模态；CREMA-D + MELD + CMU-MOSEI 三混合；7 类验证；
   fusion_strategy=standard；Class-Balanced 损失；域适应（DA）开启；50 epoch 预训练。
   变动因素：domain_loss_weight（0.02 / 0.05 / 0.10 / 默认）、学习率（1e-4 vs 5e-5）、
   采样策略（balanced vs uniform）、随机种子（默认 vs 3407）。

2. 指标汇总表（混合验证集，phase=val）

   变体              Last@49(acc/f1)   Best Acc@ep    Best F1@ep    稳定性
   ---------------------------------------------------------------------------
   DA 默认           0.548 / 0.496     0.550 @45      0.498 @45     高
   w002              0.567 / 0.509     0.571 @47      0.518 @22     高
   w005（推荐）      0.572 / 0.528     0.573 @48      0.528 @48     高
   w010              0.556 / 0.498     0.561 @45      0.506 @45     中高
   w005+lr5e5        0.271 / 0.294*    0.575 @31      0.518 @28     低（末段塌缩）
   uniform           0.530 / 0.462     0.572 @17      0.517 @24     低（后期回落）
   seed3407          0.558 / 0.513     0.563 @40      0.520 @40     高
   * w005+lr5e5 的 Last 不可用于论文；Best 经 checkpoint 重算与 CSV 一致。

3. 消融对比与规律

   （1）域损失权重（核心消融，控制 lr、采样、seed）

       默认 < w010 < w002 ≈ w005（按 Best F1）
       数值：0.498 → 0.506 → 0.518 → 0.528（Best F1）

       解读：
       - 过小（默认）：域对齐信号不足，混合数据集域偏移未充分缓解。
       - 适中（0.02–0.05）：在分类损失与域对抗之间取得平衡，w005 略优于 w002。
       - 过大（0.10）：域损失压制分类学习，峰值与末段均回落。

       结论：存在近似「倒 U 型」敏感性曲线，论文可画 domain_loss_weight–Best F1 折线图。

   （2）学习率（w005 vs w005+lr5e5）

       同域权重 0.05 下，lr 从 1e-4 降至 5e-5：
       - Best Acc 略升（0.573 → 0.575），Best F1 基本持平（0.528 vs 0.518）。
       - 但末段 val 断崖（Acc 跌至 0.27），训练过程不可靠。

       结论：低 lr 不适合作为 AP4 主配方；若论文引用 w005+lr5e5，须标注不稳定并仅报 Best。

   （3）采样策略（balanced vs uniform）

       uniform 的 Best Acc（0.572@ep17）接近 w005，但 Last 低 0.04+ Acc。
       与 AP2-M3（uniform + emotion_shift）「高峰值、末段塌」同族问题。

       结论：三混合主实验应坚持 balanced/proportional 采样；uniform 仅作负面对照。

   （4）可复现性（seed3407）

       seed3407 的 Best F1（0.520）介于 w002 与 w005 之间，未出现数量级偏差。
       支撑 AP4 主要结论（w002/w005 优于默认）具有可重复性。

4. 综合评价

   成功方面：
   - 七组扫描系统回答了「DA 是否有效、域损失权重取多少、过大/过小后果」。
   - w005 同时拿下 Best F1 与 Last F1，且续训后较中断前仍有提升，适合作为
     「标准融合 + 域适应」路线的发布检查点。
   - 与 AP2 峰值差距（~0.61 vs ~0.57）已明确归因于协议差异（emotion_shift vs standard），
     避免论文误读为「加 DA 反而变差」。

   局限与风险：
   - AP4 全程 standard 融合，未叠加 AP3 最优融合（如 leader_audio）或 AP2 最优配方
     （如 M1 有效 batch 8），故 0.57–0.58 是「DA 模块上界」而非项目全局上界。
   - w005_lr5e5、uniform 的 Best/Last 分离提醒：混合验证必须双指标报告。
   - 单卡串行耗时约 6–7 天（5 组 × ~30h），后续扩展需提前规划算力。

三、AP4 在整个项目实验体系中的位置
--------------------------------------------------------------------------------

1. 与 AP0–AP3 的逻辑关系

   AP0（noDA + standard）
     → 建立「无域适应」下混合 7 类基线（Best Acc≈0.32），说明域偏移问题严重。

   AP1（单数据集上界）
     → 证明管线在 MOSEI 等单域可达 0.70+ Acc；解释混合实验低的「数据难度」而非「代码不可用」。

   AP2（emotion_shift + 配方消融）
     → 在融合升级前提下扫 batch/lr/采样/损失，峰值 Best Acc≈0.61（M1@ep6）。
     → 选定「情绪转变感知 + 有效 batch」为高性能路线。

   AP3（融合策略消融，固定 AP2 类协议外的 standard 三混合）
     → standard / leader_audio 末段稳；leader_text 高峰值但末段差；two_stage 无效。
     → 回答「怎么融」；与 AP4 正交（AP4 固定 standard，扫「怎么对齐域」）。

   AP4（standard + DA 扫描）【本周收官】
     → 在「不改融合、不改 emotion_shift」前提下隔离 DA 因素。
     → 将混合 Acc 从 AP0 级（~0.32）拉升至 ~0.57（相对 AP0 约 +0.25 Acc），
       但仍低于 AP2 emotion_shift 峰值（~0.61）。

2. 对论文结构的支撑

   - 第 4 章「实验」可形成清晰叙事链：
     单域上界（AP1）→ 混合配方（AP2）→ 融合结构（AP3）→ 域适应（AP4）。
   - AP4 表格支撑「域损失权重敏感性分析」小节；w005 可作为 DA 线主结果行。
   - 跨表脚注必须注明：AP2/AP3 与 AP4 的 fusion、损失、采样不完全相同，禁止直接排名。

3. 对工程与智能体发布的含义

   - emotion-agent 若走「高准确率」路线：优先 AP2 最优 checkpoint（emotion_shift）。
   - 若走「标准融合 + 可解释 DA」路线：推荐 AP4 w005（稳定、F1 最高）。
   - 不宜使用 AP3 two_stage 或 AP4 w005_lr5e5 的 Last@49 权重部署。

五、阶段性结论（可供论文摘用）
--------------------------------------------------------------------------------

1. 在 AVT 三混合、standard 融合、Class-Balanced 损失设定下，启用域适应并取
   domain_loss_weight=0.05（w005），验证集 Best F1 达 0.528、Best Acc 达 0.573，
   为 AP4 七组最优且末段稳定。

2. 域损失权重呈敏感性：过小（默认）收益不足，过大（0.10）抑制分类；0.02–0.05 为甜区。

3. uniform 采样与过低学习率在相同 DA 设定下均导致「高峰值、末段塌」，须 Best/Last 分报。

4. AP4 相对 AP0 大幅提升、相对 AP2 峰值略低，说明「域对齐」与「融合/配方升级」
   是互补维度；项目最终 SOTA 需后续「AP2 配方 + AP3 融合 + AP4 DA」组合实验（若算力允许）。
