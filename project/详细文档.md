## 1. 项目概述

### 1.1 项目简介

本项目是一个基于情感计算的人机交互智能体系统，聚焦于智能驾驶领域，通过对驾驶员的多模态数据（视频、语音、文本、生理信号）进行综合分析，实现准确的驾驶员情绪识别和监测。

### 1.2 项目目标

1. **提升驾驶安全性**：通过实时监测驾驶员情绪状态，及时发现疲劳、焦虑、愤怒等负面情绪，提前预警潜在危险
2. **优化人机交互**：根据驾驶员情绪状态，智能调整车载系统交互方式，提供个性化服务
3. **推动智能驾驶发展**：将情感计算与智能驾驶结合，为自动驾驶和辅助驾驶系统提供重要的感知能力
4. **学术研究价值**：整合多模态情感分析领域的最新研究成果，为相关研究提供可复现的代码实现

### 1.3 技术特点

- **多模态融合**：整合视频、音频、生理信号和文本四种模态
- **先进融合策略**：实现CFN-ESA、MFMC、领导-跟随注意力、两阶段融合等多种融合方法
- **预训练+微调**：采用两阶段训练策略，充分利用通用数据集和驾驶员专用数据集
- **模块化设计**：代码结构清晰，易于理解和扩展
- **灵活配置**：通过配置文件灵活选择融合策略和超参数

### 1.4 主要功能

- **多模态情绪识别**：识别7种离散情绪类别（快乐、悲伤、愤怒、恐惧、中性、焦虑、其他）
- **情绪强度回归**：预测连续情绪维度（效价、唤醒度）
- **情绪趋势预测**：预测未来时间步的情绪变化（可选）
- **实时推理**：支持单样本和批量推理
- **实验管理**：支持TensorBoard和Weights & Biases进行实验跟踪

### 2.3 各文件详细说明

#### 2.3.1 models/feature_extractors.py

**功能**：定义四个特征提取器类，分别处理不同模态的数据。

**主要类**：

1. **VideoFeatureExtractor**
   - **功能**：从视频中提取面部表情特征
   - **骨干网络**：ResNet-50（ImageNet预训练）
   - **输入**：视频帧 (B, T, C, H, W) 或单帧 (B, C, H, W)
   - **输出**：视频特征 (B, T, 512) 或 (B, 512)
   - **关键方法**：
     - `__init__()`: 初始化ResNet-50和投影层
     - `forward()`: 前向传播，提取特征

2. **AudioFeatureExtractor**
   - **功能**：从音频中提取语音情感特征
   - **骨干网络**：Wav2Vec2.0（Hugging Face预训练）
   - **输入**：音频波形 (B, T)
   - **输出**：语音特征 (B, 512)
   - **关键方法**：
     - `__init__()`: 初始化Wav2Vec2和投影层
     - `forward()`: 前向传播，提取特征

3. **PhysiologicalFeatureExtractor**
   - **功能**：从生理信号中提取特征
   - **架构选择**：LSTM或1D-CNN（可配置）
   - **输入**：生理信号时序数据 (B, T, input_dim)
   - **输出**：生理特征 (B, 512)
   - **关键方法**：
     - `__init__()`: 初始化LSTM或CNN架构
     - `forward()`: 前向传播，提取特征

4. **TextFeatureExtractor**
   - **功能**：从文本中提取语义特征
   - **骨干网络**：BERT（Hugging Face预训练）
   - **输入**：文本token IDs (B, seq_len) 和注意力掩码 (B, seq_len)
   - **输出**：文本特征 (B, 512)
   - **关键方法**：
     - `__init__()`: 初始化BERT和投影层
     - `forward()`: 前向传播，提取特征

#### 2.3.2 models/attention_modules.py

**功能**：定义基础的注意力机制模块。

**主要类**：

1. **MultiHeadSelfAttention**
   - **功能**：多头自注意力机制
   - **输入**：特征序列 (B, T, hidden_dim)
   - **输出**：增强后的特征 (B, T, hidden_dim) 和注意力权重
   - **关键参数**：hidden_dim, num_heads, dropout

2. **CrossModalAttention**
   - **功能**：跨模态注意力机制，允许不同模态之间相互关注
   - **输入**：查询模态特征和键值模态特征
   - **输出**：增强后的查询模态特征
   - **应用场景**：视频-音频、文本-视频等跨模态交互

3. **TemporalAttention**
   - **功能**：时序注意力机制，处理时间序列中的长期依赖关系
   - **输入**：时序特征 (B, T, hidden_dim)
   - **输出**：加权后的特征 (B, hidden_dim) 和时序注意力权重
   - **应用场景**：连续情感识别、情绪趋势预测

4. **MultimodalFusion**
   - **功能**：标准的多模态融合模块
   - **架构**：基于Transformer，包含自注意力、跨模态注意力和前馈网络
   - **输入**：四个模态的特征
   - **输出**：融合后的特征 (B, hidden_dim)

#### 2.3.3 models/emotion_shift.py

**功能**：实现CFN-ESA方法的情感转变感知融合。

**主要类**：

2. **EmotionShiftFusion**

   - **输入**：四个模态的特征和之前的情感状态（可选）

   - **输入**：节点特征（每个模态作为一个节点）

## 3. 核心模块详解

### 3.1 特征提取器模块详解

#### 3.1.1 VideoFeatureExtractor（视频特征提取器）

**实现原理**：
1. 使用预训练的ResNet-50作为骨干网络
2. 移除最后的分类层，保留特征提取部分
3. 通过AdaptiveAvgPool2d和投影层将特征维度统一到512维

**代码位置**：`models/feature_extractors.py:12-55`

**关键代码**：
```python
class VideoFeatureExtractor(nn.Module):
    def __init__(self, backbone='resnet50', pretrained=True, feature_dim=2048, output_dim=512):
        # 加载ResNet-50
        resnet = models.resnet50(pretrained=pretrained)
        self.backbone = nn.Sequential(*list(resnet.children())[:-1])
        
        # 投影层
        self.projection = nn.Sequential(
            nn.AdaptiveAvgPool2d((1, 1)),
            nn.Flatten(),
            nn.Linear(backbone_dim, output_dim),
            nn.ReLU(),
            nn.Dropout(0.1)
        )
```

**使用示例**：
```python
video_extractor = VideoFeatureExtractor(
    backbone='resnet50',
    pretrained=True,
    output_dim=512
)
video_features = video_extractor(video_frames)  # (B, T, 512) 或 (B, 512)
```

#### 3.1.2 AudioFeatureExtractor（音频特征提取器）

**实现原理**：
1. 使用预训练的Wav2Vec2.0模型
2. 通过Wav2Vec2提取语音特征
3. 使用时序平均池化得到固定长度特征
4. 通过投影层统一维度到512维

**代码位置**：`models/feature_extractors.py:58-98`

**关键代码**：
```python
class AudioFeatureExtractor(nn.Module):
    def __init__(self, backbone='facebook/wav2vec2-base', pretrained=True, output_dim=512):
        self.backbone = Wav2Vec2Model.from_pretrained(backbone)
        self.projection = nn.Sequential(
            nn.Linear(backbone_dim, output_dim),
            nn.ReLU(),
            nn.Dropout(0.1)
        )
```

**使用示例**：
```python
audio_extractor = AudioFeatureExtractor(
    backbone='facebook/wav2vec2-base',
    pretrained=True,
    output_dim=512
)
audio_features = audio_extractor(audio_waveform)  # (B, 512)
```

**使用示例**：

#### 3.1.4 TextFeatureExtractor（文本特征提取器）

**实现原理**：
1. 使用预训练的BERT模型

### 3.2 融合模块详解

#### 3.2.1 标准融合（MultimodalFusion）

**实现原理**：
1. 将所有模态特征堆叠为 (B, num_modalities, hidden_dim)
2. 通过多层Transformer编码器处理
3. 使用平均池化得到融合后的特征

**代码位置**：`models/attention_modules.py:167-248`

**特点**：
- 基础的多模态融合方法
- 适用于简单的多模态融合任务
- 作为其他融合方法的对比基线

#### 3.2.2 情感转变感知融合（EmotionShiftFusion）

**实现原理**：
1. 加权融合多模态特征（文本权重更高）
2. 应用情感转变感知，捕捉情感变化模式
3. 跨模态注意力融合，以文本引导其他模态
4. 残差连接和层归一化

**代码位置**：`models/emotion_shift.py:101-186`

**特点**：
- 能够捕捉情绪的动态变化
- 文本模态主导，符合对话场景特点
- 适用于连续情感识别

**使用配置**：
```yaml
model:
  attention:
    fusion_strategy: "emotion_shift"
```

#### 3.2.3 领导-跟随注意力融合（MultimodalLeaderFollowerFusion）

**实现原理**：
1. 确定领导者模态（默认文本）
2. 使用领导-跟随注意力，领导者引导每个跟随者
3. 融合所有增强后的模态特征

**代码位置**：`models/leader_follower_attention.py:167-228`

**特点**：
- 允许模态之间相互引导
- 适用于连续情感识别任务
- 灵活的领导者选择

**使用配置**：
```yaml
model:
  attention:
    fusion_strategy: "leader_follower"
    leader_modal: "text"  # 可选: "text", "physiological"
```

#### 3.2.4 两阶段融合（TwoStageFusion）

**实现原理**：
1. **第一阶段**：使用图注意力网络进行上下文建模
2. **第二阶段**：使用跨模态注意力进行多模态融合
3. 最终融合所有模态特征

**代码位置**：`models/two_stage_fusion.py:58-211`

**特点**：
- 两阶段设计，更好地捕捉模态内和模态间的依赖关系
- 图注意力网络能够建模复杂的模态交互关系
- 适用于复杂的多模态融合场景

**使用配置**：
```yaml
model:
  attention:
    fusion_strategy: "two_stage"
    num_gat_layers: 2
```

```python
import cv2

def extract_frames(video_path, fps=30, num_frames=16):
    """
    从视频中提取固定数量的帧
    
    Args:
        video_path: 视频文件路径
        fps: 目标帧率
        num_frames: 提取的帧数
    
    Returns:
        frames: 提取的帧列表
    """
    cap = cv2.VideoCapture(video_path)
    frames = []
    frame_count = 0
    
    while cap.isOpened():
        ret, frame = cap.read()
        if not ret:
            break
        
        # 调整大小到224x224
        frame = cv2.resize(frame, (224, 224))
        # BGR转RGB
        frame = cv2.cvtColor(frame, cv2.COLOR_BGR2RGB)
        frames.append(frame)
        frame_count += 1
    
    cap.release()
    
    # 采样固定数量的帧
    if len(frames) > num_frames:
        indices = np.linspace(0, len(frames) - 1, num_frames, dtype=int)
        frames = [frames[i] for i in indices]
    elif len(frames) < num_frames:
        # 重复最后一帧
        frames.extend([frames[-1]] * (num_frames - len(frames)))
    
    return frames
```

**步骤2：滤波处理**
```python
def filter_physiological_signal(data, sampling_rate=128, lowcut=0.5, highcut=40):
    """
    对生理信号进行带通滤波
    
    Args:
        data: 生理信号数据 (T, channels)
        sampling_rate: 采样率（Hz）
        lowcut: 低截止频率（Hz）
        highcut: 高截止频率（Hz）
    
    Returns:
        filtered_data: 滤波后的数据
    """
    nyquist = sampling_rate / 2
    low = lowcut / nyquist
    high = highcut / nyquist
    
    # 设计带通滤波器
    b, a = signal.butter(4, [low, high], btype='band')
    
    # 对每个通道进行滤波
    filtered_data = np.zeros_like(data)
    for i in range(data.shape[1]):
        filtered_data[:, i] = signal.filtfilt(b, a, data[:, i])
    
    return filtered_data
```

**步骤3：归一化**
```python
def normalize_physiological_signal(data):
    """
    归一化生理信号
    
    Args:
        data: 生理信号数据 (T, channels)
    
    Returns:
        normalized_data: 归一化后的数据
    """
    # Z-score归一化
    mean = np.mean(data, axis=0, keepdims=True)
    std = np.std(data, axis=0, keepdims=True)
    normalized_data = (data - mean) / (std + 1e-8)
    
    return normalized_data
```

**步骤4：时间窗口分割**
```python
def segment_physiological_signal(data, window_size=5.0, sampling_rate=128, overlap=0.5):
    """
    将生理信号分割成固定长度的时间窗口
    
    Args:
        data: 生理信号数据 (T, channels)
        window_size: 窗口大小（秒）
        sampling_rate: 采样率（Hz）
        overlap: 重叠比例
    
    Returns:
        segments: 分割后的数据段列表
    """
    window_length = int(window_size * sampling_rate)
    step = int(window_length * (1 - overlap))
    
    segments = []
    for i in range(0, len(data) - window_length + 1, step):
        segment = data[i:i+window_length, :]
        segments.append(segment)
    
    return segments
```

```python
    # 2. 预处理音频
    audio_path = os.path.join(data_dir, 'audio', f'{sample_id}.wav')
    if os.path.exists(audio_path):
        audio = preprocess_audio(audio_path,
                               target_sr=config['data']['audio']['sample_rate'],
                               duration=config['data']['audio']['duration'])
        processed_data['audio'] = torch.from_numpy(audio).float()
    
    # 3. 预处理生理信号
    physio_path = os.path.join(data_dir, 'physiological', f'{sample_id}.npy')
    if os.path.exists(physio_path):
        physio_data = load_physiological_data(physio_path)
        physio_data = filter_physiological_signal(physio_data)
        physio_data = normalize_physiological_signal(physio_data)
        processed_data['physiological'] = torch.from_numpy(physio_data).float()
    
    # 4. 预处理文本
    text_path = os.path.join(data_dir, 'text', f'{sample_id}.txt')
    if os.path.exists(text_path):
        with open(text_path, 'r', encoding='utf-8') as f:
            text = f.read().strip()
        text = clean_text(text)
        tokenizer = BertTokenizer.from_pretrained(config['model']['text']['backbone'])
        input_ids, attention_mask = tokenize_text(text, tokenizer)
        processed_data['text_input_ids'] = input_ids
        processed_data['text_attention_mask'] = attention_mask
    
    # 5. 加载标签
    label_path = os.path.join(data_dir, 'labels', f'{sample_id}.txt')
    if os.path.exists(label_path):
        emotion_label, emotion_dimensions = load_label(label_path)
        processed_data['emotion_label'] = emotion_label
        processed_data['emotion_dimensions'] = emotion_dimensions
    
    return processed_data
```

## 6. 模型微调详细指南

### 6.1 微调策略

#### 6.1.1 冻结vs微调

**策略1：完全微调**
- 所有参数都参与训练
- 学习率通常较小（1e-5）
- 适用于数据量充足的情况

**策略2：部分冻结**
- 冻结特征提取器的底层，只微调顶层
- 完全微调融合模块和输出层
- 适用于数据量有限的情况

**策略3：渐进式解冻**
- 先冻结所有层，训练输出层
- 逐步解冻更多层
- 适用于迁移学习

#### 6.1.2 微调配置

## 10. 常见问题与解决方案

### 10.1 环境配置问题

#### 问题1：CUDA不可用

**症状**：`torch.cuda.is_available()`返回False

**解决方案**：
1. 检查CUDA驱动版本：`nvidia-smi`
2. 检查PyTorch CUDA版本：`python -c "import torch; print(torch.version.cuda)"`
3. 重新安装匹配的PyTorch版本：
```bash
# 访问 https://pytorch.org/ 获取正确的安装命令
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu118
```

#### 问题2：依赖包版本冲突

**症状**：导入错误或运行时错误

**解决方案**：
1. 使用虚拟环境隔离依赖
2. 检查requirements.txt中的版本要求
3. 使用`pip install --upgrade`更新包

### 10.2 数据加载问题

#### 问题1：数据文件找不到

**症状**：`FileNotFoundError`或数据加载失败

**解决方案**：
1. 检查数据路径配置：`config.yaml`中的`data.root_dir`
2. 检查CSV文件中的路径是否正确
3. 使用绝对路径或确保相对路径正确

#### 问题2：内存不足

**症状**：`OutOfMemoryError`或系统卡死

**解决方案**：
1. 减小batch_size
2. 减少num_workers
3. 使用数据流式加载，不要一次性加载所有数据
4. 使用梯度累积

### 10.3 训练问题

#### 问题1：损失不下降

**症状**：训练损失和验证损失都不下降

**解决方案**：
1. 检查学习率是否过大或过小
2. 检查数据标签是否正确
3. 检查模型初始化是否正确
4. 尝试使用预训练模型

#### 问题2：过拟合

**症状**：训练损失下降但验证损失上升

**解决方案**：
1. 增加Dropout率
2. 增加权重衰减（weight_decay）
3. 使用数据增强
4. 减少模型复杂度
5. 使用早停机制

#### 问题3：梯度爆炸

**症状**：损失变为NaN或非常大

**解决方案**：
1. 使用梯度裁剪：`torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)`
2. 减小学习率
3. 检查数据预处理是否正确（归一化等）

### 10.4 模型推理问题

#### 问题1：推理速度慢

**症状**：单样本推理时间过长

**解决方案**：
1. 使用GPU推理
2. 批量处理多个样本
3. 使用模型量化
4. 优化数据预处理流程

#### 问题2：推理结果不一致

**症状**：相同输入得到不同结果

**解决方案**：
1. 设置随机种子：`torch.manual_seed(42)`
2. 确保模型处于eval模式：`model.eval()`
3. 使用`torch.no_grad()`禁用梯度计算

### 10.5 多模态融合问题

#### 问题1：某个模态缺失

**症状**：某个模态的数据不存在

**解决方案**：
- 模型已经支持缺失模态处理，会自动使用零特征填充
- 确保数据加载器正确处理None值

#### 问题2：模态对齐问题

**症状**：不同模态的时间戳不一致

**解决方案**：
1. 使用时间窗口对齐
2. 使用注意力机制处理异步数据
3. 预处理时进行时间对齐

### 10.6 性能调优问题

#### 问题1：训练速度慢

**解决方案**：
1. 使用GPU训练
2. 增加num_workers
3. 使用混合精度训练
4. 优化数据预处理流程

#### 问题2：内存占用大

**解决方案**：
1. 减小batch_size
2. 使用梯度检查点（gradient checkpointing）
3. 使用模型量化
4. 清理不需要的中间变量
