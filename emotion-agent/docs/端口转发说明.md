# Cursor 端口转发（已尽量自动配置）

## 推荐：单端口模式（最简单）

已在项目里配好 **页面 + API 都在 8000**，不再依赖 5173 代理大文件。

```bash
cd emotion-agent
./scripts/start_demo.sh
```

浏览器打开：**http://127.0.0.1:8000**（不是 5173）

### Cursor 里只需转发 8000

1. 看底部 **「端口 / Ports」** 面板  
2. 若没有 8000，点 **「转发端口 / Forward a Port」**，输入 `8000`  
3. 或等弹窗 **Forward Port 8000** 时点允许  

工作区已写入 `.vscode/settings.json`，后端启动后 Cursor 通常会**自动提示**转发 8000。

---

## 开发模式（可选）

若坚持用 `npm run dev`（5173），需**同时**转发 **8000** 和 **5173**，且 `frontend/.env.local` 中：

```env
VITE_API_BASE_URL=http://127.0.0.1:8000
```

---

## 自检

Windows 本机浏览器地址栏打开：

```text
http://127.0.0.1:8000
```

能看到「情绪助手控制台」即成功。
