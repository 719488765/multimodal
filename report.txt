# 多模态驾驶员情绪分析研究工作报告

## 一、数据集搜集

本研究针对智能驾驶场景下的多模态情感识别需求，系统搜集和整理了相关数据集，主要分为三类：

### 1.1 通用多模态情感数据集

**CMU-MOSEI / CMU-MOSI**
- 大规模多模态情感数据集，包含视频、音频、文本三种模态
- 来自YouTube的多模态数据，包含来自1000位YouTube用户的3228条视频
- 标注了情感类别和强度，是评估多模态情感识别方法的重要基准
- 适用性：数据量大，适合预训练模型，但场景与驾驶环境不同，需要通过迁移学习适配

**IEMOCAP（Interactive Emotional Dyadic Motion Capture）**
- 交互式情感对话数据集，包含高质量的多模态情感数据
- 包含视频、音频和文本三种模态，特别适合研究对话场景下的情感识别
- 包含5个对话会话，数据质量高但规模相对较小
- 适用性：适合研究语音-文本-视觉的跨模态关联，作为验证集评估模型性能

**MAFW（Multi-modal Affective Database for Facial Expression Recognition）**
- 包含10,045个视频-音频片段，涵盖面部表情和语音
- 标注了11种复合情感类别（愤怒、厌恶、恐惧、快乐、中性、悲伤、惊讶、蔑视、焦虑、无助、失望）
- 包含描述性文本，可用于多模态融合
- 适用性：虽然不是专门针对驾驶员，但包含丰富的面部表情和语音数据，可用于训练面部表情识别和语音情感识别的基础模型

**MELD / M3ED / EmotionTalk**
- 对话场景的多模态情感数据
- 适合研究驾驶员与车载系统的交互情感
- 包含时序信息，适合LSTM/Transformer模型
- 适用性：训练驾驶员-车载系统交互情感分析模型，研究对话中的情感变化模式

**AffectNet**
- 大型面部表情数据集，包含超过100万张带有情感标签的面部图像
- 适用性：用于预训练面部表情识别模型，提供大规模数据支持

### 1.2 中文多模态情感数据集

**VCEMO（中文语音多模态情感识别数据集）**
- 专注于中文语音的多模态情感识别
- 包含来自100多名用户的7,747个文本样本
- 适用性：适合中文环境下的智能驾驶应用，训练中文语音情感识别模型

**BUPT多模态数据集**
- 北京邮电大学提供的多模态数据集
- 适用于跨模态检索和情感分析
- 适用性：作为中文多模态情感分析的补充数据，研究跨模态特征学习

### 1.3 智能驾驶相关数据集

**MPDB（多模态生理驾驶员行为数据库）**
- 包含35名参与者的多模态生理数据
- 包含脑电图（EEG）、心电图（ECG）、肌电图（EMG）、皮肤电反应（GSR）和眼动数据
- 在驾驶模拟器中采集，接近真实驾驶场景
- 适用性：最适合驾驶员情绪分析，作为核心数据集训练基于生理信号的驾驶员情感识别模型

**DEFE（驾驶员情感面部表情数据集）**
- 包含60名参与者在驾驶过程中自发的面部表情记录
- 专门针对驾驶员设计，最适合驾驶员情绪分析
- 适用性：驾驶员面部表情识别，与其他模态数据结合构建多模态情绪分析系统

**HDD（Honda Research Institute Driving Dataset）**
- 包含104小时真实人类驾驶数据
- 主要关注驾驶场景和车辆行为，不包含驾驶员多模态情感数据
- 适用性：可作为辅助数据，用于理解驾驶场景，分析不同场景对驾驶员情绪的影响

**BDD100K**
- 大规模驾驶视频数据（10万个视频）
- 涵盖多种驾驶场景和天气条件
- 适用性：用于场景-情感关联分析，理解驾驶环境对情绪的影响，但不推荐单独用于驾驶员情绪分析

### 1.4 数据集组合使用策略

本研究采用预训练+微调的两阶段策略：

**预训练阶段数据集**：
- 面部表情：MAFW + AffectNet
- 语音情感：IEMOCAP + VCEMO（中文）
- 多模态融合：CMU-MOSEI + MELD

**微调阶段数据集**：
- 生理信号：MPDB（核心数据集）
- 面部+语音：MAFW（迁移到驾驶员场景）
- DEFE（如可获得，专门针对驾驶员的面部表情）

## 二、相关论文查找

本研究系统查找和整理了多模态情感识别、驾驶员情绪分析和智能驾驶方向的相关论文，主要分为以下几类：

### 2.1 多模态情感识别与注意力融合

**CFN-ESA: A Cross-Modal Fusion Network with Emotion-Shift Awareness for Dialogue Emotion Recognition**
- 作者：Jiang Li, Xiaoping Wang, Yingjian Liu, Zhigang Zeng
- 发表时间：2023年7月
- 核心创新点：提出跨模态融合网络（CFN-ESA），具有情感转变感知能力；将文本模态作为主要情感信息来源，视觉和音频模态作为次要来源；引入情感转移模块，捕捉对话中的情感变化
- 与本研究关联性：⭐⭐⭐⭐⭐ 跨模态融合机制可直接应用于驾驶员多模态情绪分析，情感转变感知有助于理解驾驶员情绪的动态变化

**Multimodal Functional Maximum Correlation for Emotion Recognition（MFMC）**
- 作者：Deyang Zheng, Tianyi Zhang, Wenming Zheng, Shujian Yu
- 发表时间：2025年12月（预印本）
- 核心创新点：提出多模态功能最大相关（MFMC）的自监督学习框架；通过双重总相关目标最大化多模态依赖性；使用功能最大相关（FMC）方法捕捉多模态之间的高阶相关性
- 与本研究关联性：⭐⭐⭐⭐⭐ 自监督学习框架可用于预训练阶段，最大化多模态依赖性的思想可应用于注意力融合模块

**Continuous Emotion Recognition with Audio-visual Leader-follower Attentive Fusion**
- 作者：Su Zhang, Yi Ding, Ziquan Wei, Cuntai Guan
- 发表时间：2021年7月，ICCV 2021（CCF-A类）
- 核心创新点：提出音频-视觉时空深度神经网络；包含视觉块、听觉块和领导-跟随注意力融合块；领导-跟随注意力机制允许一个模态引导另一个模态的特征学习
- 与本研究关联性：⭐⭐⭐⭐ 领导-跟随注意力机制可应用于多模态融合，连续情感识别适用于实时驾驶员情绪监测

**GA2MIF: Graph and Attention Based Two-Stage Multi-Source Information Fusion**
- 作者：Jiang Li, Xiaoping Wang, Guoqing Lv, Zhigang Zeng
- 发表时间：2022年7月
- 核心创新点：提出基于图和注意力的两阶段多源信息融合方法；使用多头有向图注意力网络（MDGATs）进行上下文建模；使用多头成对跨模态注意力网络（MPCATs）进行跨模态建模
- 与本研究关联性：⭐⭐⭐⭐ 两阶段融合策略可参考，图注意力网络可建模多模态交互关系，跨模态注意力机制可直接应用

### 2.2 驾驶员情绪与行为分析

**CPSOR-GCN: A Vehicle Trajectory Prediction Method Powered by Emotion and Cognitive Theory**
- 作者：L. Tang, Y. Li, J. Yuan, A. Fu, J. Sun
- 发表时间：2023年11月
- 核心创新点：结合物理层面的图卷积网络（GCN）和认知层面的动态贝叶斯网络（DBN）；量化情绪对驾驶行为的影响；预测精度提升68.70%
- 与本研究关联性：⭐⭐⭐⭐⭐ 最相关，直接研究情绪对驾驶行为的影响，GCN可用于建模驾驶员-车辆-环境的交互关系

**A Unified Multi-scale and Multi-task Learning Framework for Driver Behaviors Reasoning**
- 作者：Yang Xing, Chen Lv, Dongpu Cao, Efstathios Velenis
- 发表时间：2020年3月
- 会议：IEEE Transactions on Intelligent Transportation Systems
- 核心创新点：统一的多尺度、多任务学习框架；同时识别驾驶员的身体姿势、意图和情绪；基于深度编码器-解码器结构
- 与本研究关联性：⭐⭐⭐⭐⭐ 高度相关，直接研究驾驶员情绪识别，多任务学习框架可扩展应用到多模态情绪分析

### 2.3 其他相关论文

还查找了包括Self Context-Aware Emotion Perception、V2X-ViT、Holistic Transformer、CRAT-Pred等多篇相关论文，为研究提供了丰富的理论基础和方法借鉴。

## 三、整体研究思路

### 3.1 研究目标与技术方案

本研究旨在构建一个面向智能汽车场景的多模态情感交互智能体，通过融合文本、语音、视觉和生理信号等多模态信息，实现对驾驶员情绪的精准识别，并将情绪作为注意力机制增强对驾驶员意图的理解。

**技术方案选择**：
- **特征融合方式**：注意力融合（Attention Fusion）
- **训练策略**：多模态预训练 + 驾驶员数据微调
- **数据集组合**：预训练+微调策略

### 3.2 数据集使用策略

**预训练阶段**：
1. 使用通用多模态情感数据集（MAFW、AffectNet、IEMOCAP、CMU-MOSEI等）进行预训练
2. 学习多模态特征提取和基础融合能力
3. 可选：使用功能最大相关损失（MFMC）进行自监督预训练

**微调阶段**：
1. 使用驾驶员专用数据集（MPDB、DEFE等）进行微调
2. 适配驾驶场景的特殊性（如光照变化、噪声干扰等）
3. 优化模型在真实驾驶环境下的表现

### 3.3 论文方法整合

本研究深度借鉴了多篇顶会论文的优秀方法：

1. **CFN-ESA方法**：借鉴情感转变感知机制，捕捉驾驶员情绪的动态变化
2. **MFMC方法**：引入多模态功能最大相关自监督学习框架，提高预训练阶段的特征学习能力
3. **领导-跟随注意力**：借鉴Continuous Emotion Recognition方法，实现模态之间的相互引导
4. **两阶段融合**：借鉴GA2MIF方法，通过两阶段设计更好地捕捉模态内和模态间的依赖关系

### 3.4 研究阶段划分

**阶段一：数据准备与预处理**（1-2个月）
- 获取并预处理预训练数据集
- 获取并预处理微调数据集
- 数据标注与对齐
- 数据增强策略设计

**阶段二：模型预训练**（2-3个月）
- 实现多模态特征提取模块
- 实现注意力融合模块
- 在通用数据集上进行预训练
- 验证预训练模型性能

**阶段三：模型微调**（1-2个月）
- 在驾驶员数据集上进行微调
- 超参数调优
- 模型性能评估

**阶段四：实验与优化**（1-2个月）
- 消融实验
- 不同融合策略对比
- 模型优化与改进

**阶段五：系统集成与测试**（1个月）
- 模型部署
- 实时性能测试
- 系统集成

## 四、模型架构

### 4.1 整体架构设计

本研究构建的多模态情绪分析模型采用层次化设计，主要包括以下部分：

**输入层（多模态数据）**：
- 视频模态：驾驶员面部视频
- 语音模态：驾驶员语音/音频
- 生理信号：EEG、ECG、GSR、眼动数据
- 文本模态：语音转文本或交互文本

**特征提取层（预训练模型）**：
- 视频特征提取器：ResNet-50 → 面部表情特征
- 语音特征提取器：Wav2Vec2 → 语音情感特征
- 生理信号特征提取器：1D-CNN/LSTM → 生理特征
- 文本特征提取器：BERT → 文本语义特征

**多模态融合层（核心模块，支持多种策略）**：
- 标准融合（MultimodalFusion）：基础的多模态融合
- 情感转变感知融合（EmotionShiftFusion）：CFN-ESA方法
- 领导-跟随注意力融合（MultimodalLeaderFollowerFusion）：Continuous Emotion Recognition方法
- 两阶段融合（TwoStageFusion）：GA2MIF方法

**输出层**：
- 情绪分类器：离散情绪类别（快乐、悲伤、愤怒、恐惧、中性、焦虑等）
- 情绪强度回归器：连续情绪维度（效价、唤醒度）
- 情绪趋势预测器：时序情绪变化预测（可选）

### 4.2 使用的数据集

**预训练阶段数据集**：
- **MAFW**：多模态情感数据库（面部+语音），用于训练面部表情识别和语音情感识别的基础模型
- **AffectNet**：大规模面部表情数据库，用于预训练面部表情识别模型
- **IEMOCAP**：交互式情感对话数据库，用于训练语音情感识别模块
- **CMU-MOSEI**：大规模多模态情感数据集，用于学习多模态特征融合方法
- **VCEMO**：中文语音多模态情感识别数据集，用于中文语音情感识别

**微调阶段数据集**：
- **MPDB**：多模态生理驾驶员行为数据库（核心数据集），包含生理信号和情绪标注，用于驾驶员情绪分析的微调
- **MAFW**：可迁移到驾驶员场景，用于驾驶员面部表情和语音情感识别
- **DEFE**：驾驶员情感面部表情数据集（如可获得），专门针对驾驶员设计

### 4.3 借鉴的论文方法

模型架构深度借鉴了以下论文的方法：

1. **CFN-ESA（情感转变感知融合）**：
   - 情感转变感知模块：使用LSTM检测情感变化模式
   - 跨模态融合网络：文本模态主导，其他模态辅助
   - 实现位置：models/emotion_shift.py

2. **MFMC（多模态功能最大相关）**：
   - 功能最大相关模块：最大化多模态依赖性
   - 多模态相关性损失：用于预训练阶段
   - 实现位置：models/functional_correlation.py

3. **Continuous Emotion Recognition（领导-跟随注意力）**：
   - 领导-跟随注意力机制：一个模态引导另一个模态
   - 双向领导-跟随：允许模态之间相互引导
   - 实现位置：models/leader_follower_attention.py

4. **GA2MIF（两阶段融合）**：
   - 第一阶段：图注意力网络进行上下文建模
   - 第二阶段：跨模态注意力进行多模态融合
   - 实现位置：models/two_stage_fusion.py

### 4.4 技术栈

**深度学习框架**：
- PyTorch：主要深度学习框架，灵活、易调试，适合研究

**预训练模型**：
- **视频**：ResNet-50（ImageNet预训练）
- **语音**：Wav2Vec2（Hugging Face）
- **文本**：BERT（Hugging Face）
- **生理信号**：自定义1D-CNN/LSTM架构

**工具库**：
- **数据处理**：NumPy, Pandas, OpenCV
- **音频处理**：Librosa, torchaudio
- **生理信号处理**：MNE-Python, SciPy
- **NLP**：Transformers (Hugging Face)
- **可视化**：Matplotlib, Seaborn, TensorBoard

**实验管理**：
- **版本控制**：Git
- **实验跟踪**：Weights & Biases, MLflow
- **模型管理**：Hugging Face Hub

### 4.5 融合策略选择

项目支持四种融合策略，可通过配置文件选择：

1. **standard**：标准的多模态融合（基础方法）
2. **emotion_shift**：情感转变感知融合（推荐，CFN-ESA方法）
3. **leader_follower**：领导-跟随注意力融合（Continuous Emotion Recognition方法）
4. **two_stage**：两阶段融合（GA2MIF方法）

## 总结

本研究通过系统搜集多模态情感数据集和智能驾驶相关数据集，查找和整理了多篇顶会论文的优秀方法，构建了面向智能汽车场景的多模态情感交互系统。研究采用预训练+微调的两阶段策略，整合了CFN-ESA、MFMC、领导-跟随注意力、GA2MIF等多种先进的融合方法，使用PyTorch框架和多种预训练模型，实现了完整的系统架构。后续将进行模型训练、实验评估和系统优化，最终实现可落地的智能座舱情感交互解决方案。
